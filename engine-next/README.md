# Hexo 8 compatibility candidate (not production)
Install with npm ci --ignore-scripts. Copy package.json and package-lock.json into an isolated copy of the prepared Butterfly source; change the two legacy logger declarations in themes/butterfly/scripts/events to const logger = hexo.log. Generate using the same config/root as the old build. Run compare.py OLD_PUBLIC NEW_PUBLIC. A nonzero exit blocks activation. Current candidate has 137 matching article routes and titles but structural differences remain in text-style and gene-engineering articles. Keep the production engine unchanged until these and browser regressions are resolved. The legacy Markdown renderer 5.0.0 trial did not resolve these differences and had known audit findings, so the candidate uses 7.1.1.
