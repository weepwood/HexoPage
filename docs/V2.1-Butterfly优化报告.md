# HALO V2.1 · 原版 Butterfly 主题优化

## 方向修正

用户明确要求保留原有 Butterfly 设计而非换主题。本次以原始 Butterfly 3.7.5-b3 为视觉基础，保留交替封面卡片、作者信息与标签/归档侧栏、原导航、文章布局、原有特殊 Markdown 标签、阅读模式及暗色主题。V1.0.0、V2.0.0 标签均不移动；V2.0.0 独立极简主题继续作为历史预览，而不再作为主站。

## 实施

- `butterfly-optimized/` 为独立兼容优化层；构建临时副本，不改原主题及文章文件。保留 Hexo 5.4 以降低旧主题插件回归风险，独立新版 Hexo 8 极简分支构建路径不变。
- 复用 clean-css、Terser 压缩主题 CSS、主要 JS，合并本地 CSS import。关闭页面进入动画及 instantpage 自动预取；使用浏览器原生图片懒加载，首个封面和头像保留立即加载；隐藏/离屏时停止横幅绘制，遵守 reduced-motion。
- 本地化 Font Awesome 5.15.4、jQuery 3.7.1、Fancybox 3.5.7、font-awesome-animation 0.3.0，锁定依赖及许可证。移除全站远端大字体和自定义光标，使用系统中文字体与等宽字体，避免阻塞式第三方字体请求；评论延迟加载。删除未使用的 issues 脚本。
- 保持 Butterfly 原搜索面板，采用标题索引快速反馈，用户输入后按需获取纯文本全文索引。安全 DOM 渲染、键盘 Ctrl/Cmd+K 和 Escape、输入竞态处理；保留原 XML 供兼容使用。
- 轻度精修阴影、边框、正文行高、暗色标签与页脚对比度、键盘焦点。非重绘主题，不改变原封面比例或侧栏信息架构。
- 保留 137 篇文章。对 11 篇缺日期文章沿用 V2 的日期策略和兼容跳转；不改原文。原冬秋图床失效问题继续使用历史春季横幅兼容层。

大小为未压缩静态产物；CSS 还包含本地合并的自定义 main.css，图标库亦独立存在，不能将单文件降幅直接视作页面总传输量或真实 LCP 改善。Chromium 在拦截外部资源的本地测试中验证首页 10 个封面卡片、4 个侧栏组件、搜索 Hexo 返回 5 条全文结果、Escape、文章、归档、分类、标签和 375px 宽度均通过，无 JS 异常及本地资源失败。外链封面、头像、部分历史正文资源、评论及数学服务仍可能受网络影响，未逐篇检查。生产 CI 和线上复验另行确认。
