# HALO V2.5 质量深化报告

基线：V2.4.0 已上线，保留 Butterfly 卡片、导航、侧栏、背景、字体、横幅及历史标签。

- 统一明暗主题色彩、正文、代码、目录和提示组件。已查看桌面明暗首页截图，移动端为自动化测试。
- 本地固定 MathJax 3.2.2，修复选择器及版本路径；公式页加载，vendor 静态文件不参与模板渲染。
- 1024、1440、1920px 横幅短时采样中位帧间隔均 16.7ms，鼠标移出回中通过。不是持续 GPU 压力测试。
- 真实网络 V2.4 首页基准：桌面 LCP 1512ms、CLS 0.001388、INP 32ms；Pixel 7 模拟 LCP 544ms、CLS 0.000521、INP 32ms。未限速、各一次，非真机或长期用户统计。
- 桌面与 Pixel 7 模拟：4 个公式、0 个公式错误，16 代码块、17 Tab、36 Note，无横向溢出及本地请求或 JS 错误。WebKit 下载解压未完成，iOS Safari 与 Android 真机仍待验。
- 137 篇 BlogPosting JSON-LD，canonical 路径校验、OG 图片绝对路径、分页与标题锚点、表单标签、键盘焦点、装饰图空 alt。未知历史图片文字描述明确标记。
- axe-core 最终两页无自动识别违规，仍有 2/3 项需人工确认。不是全站 WCAG 认证。
- CSS 保守去重，main.css 本轮由 43985 B 降到 43762 B。仍需更深入历史样式治理。
- Hexo 8.1.2 隔离候选：137 篇 URL/标题一致，两个旧日志 API 修复，仍有两篇文章的代码、表格、Tab 和图片计数差异；不切换生产。依赖审计仍有告警，须收口后才启用。
- 本地构建及 Pagefind 均包含 137 篇文章；49 个缺失来源继续使用占位。
- 可复现脚本位于 tests/，原始记录位于 docs/quality/v2.5/，迁移比较位于 engine-next/。V2.5 正式生产部署尚未确认。
