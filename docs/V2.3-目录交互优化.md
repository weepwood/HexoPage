# V2.3 · Butterfly 文章目录交互优化

基于 V2.2.0，保留主题及图片、字体、横幅资源策略。原目录通过固定滚动步长、按方向不同的标题偏移和每次清空 active 类实现切换，容易出现抖动、错位和不可中断动画。新版在构建副本替换 tocFn，其他历史版本不变。

- 按实际标题 ID 映射，处理中文锚点；统一导航高度 + 18px 安全偏移，目标限制在页面滚动范围。
- 300–680ms 三次缓动，连续点击取消旧 RAF；滚轮、触控和键盘滚动取消跳转。跳转锁定目标高亮，完成后恢复 scrollspy。
- 标题位置缓存与二分查找；图片加载、正文尺寸改变、字体完成及窗口尺寸变化使缓存失效。每帧最多一次滚动监听计算。
- 侧栏自动跟随使用实际可见边界，避免固定步长跳动；手动滚动侧栏后短暂暂停跟随。独立子目录展开/折叠、当前路径展开、长标题换行、低饱和选中样式和阅读进度。
- URL hash 支持直接定位及浏览器前进/后退。移动端保留原右侧目录按钮，选中后关闭浮层，支持 Escape 与 reduced-motion。

## 实际验证

本地 Hexo 构建生成 812 个文件；真实 Chromium 在 274 项目录、16 个根章节的《基因工程》上检查向下、远距离、向上、100ms 间隔连续点击、历史返回、375px 移动目录与 reduced-motion。统一目标偏移 78px，实测 77.5–77.875px，只有一个 active 链接；测试范围无 JS 异常及本地资源错误。远程资源在该交互测试中被拦截以排除网络干扰。未进行所有文章人工视觉回归或跨浏览器性能基准；生产 CI/线上检查独立确认。
