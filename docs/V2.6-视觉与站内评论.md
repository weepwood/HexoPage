# V2.6 视觉系统与站内评论

保留 Butterfly 交替封面、导航、侧栏、文章与 15 层原始横幅。新增独立 design.css，在构建中与 refine.css 合并并压缩，不改历史标签或文章原文。

- Inter + Noto Sans SC 400–700 可变远程字体，WOFF2 分片、swap、系统降级；等宽代码字体独立。实际 Chromium 收到远程字体响应。
- 浅色 #f4f6fa / #fff，深色 #10141b / #191f29；低饱和渐变替代旧彩虹，单一蓝色强调、明确正文/辅助文字与表面层级。统一卡片圆角、边线、阴影、标签、导航、搜索、目录、右侧操作及阅读排版。
- 160/260ms 交互节奏、420ms 封面轻微放大、220ms 搜索入场；减少动态效果时取消封面变换。不引入全页阻塞动画，不改横幅引擎。
- 412px 移动首页增加 12px 外侧留白、14px 卡片间距，恢复文章时间与标签。真实桌面 1440px 和 Pixel 7 模拟双主题截图检查，10 个首页卡片、无横向溢出、无 JS 或本地资源错误；hover 与 reduced-motion 验证通过。不是 Safari/安卓真机验收。
- GitHub Discussions 已启用，Giscus 官方接口与真实 iframe 验证授权已生效，中文界面显示 0 条评论、输入/预览及 GitHub 登录。现用 Announcements 分类与稳定路径 specific/strict 键；141 个评论区域，历史 Issues 折叠备用，旧 Valine 未恢复。首次登录仍由 GitHub 授权；没有实际发布测试评论。网络异常与主题同步使用模拟测试。
- 保留 GitHub Pages 唯一正式部署平台；137 篇文章、Pagefind、历史版本与本地图片策略不变。最终线上性能和真实评论发表需部署后核验。
