# V2.8 透明导航与内页精修

基线 V2.7.0，生产 Actions 45606568210 已成功。参考实际访问的 DeepSeek 首页（https://deepseek.com/）顶部布局、文字与透明材质，不复制品牌资产。原 Butterfly 文章、导航功能、侧栏、15 层春季横幅、Giscus 和历史版本保留。

- 首页及有图页整条顶栏透明（background-image none、background-color rgba(0,0,0,0)）。品牌和右侧菜单按约 1170px 内容宽度对齐，桌面去除重复主菜单图标，保留搜索和下拉箭头。
- 图片上的局部对比表面：浅色 rgba(250,252,255,.90) / #172437，深色 rgba(25,34,48,.91) / #edf3ff；支持时局部 8px backdrop-filter。不是动态像素取色，避免随视差改变文字颜色及额外计算。复杂春季插画标题亦使用小面积主题表面。滚动向上时使用当前主题实体表面而非黑色。
- 导航独立模块 navigation.js：当前页面 aria-current、垂直下拉、指针与键盘交互、Escape 关闭、搜索与移动菜单键盘入口。沿用 Butterfly 菜单与搜索逻辑。样式 pages.css 统一归档标题、时间线条目、分类、标签、正文 Tab 的令牌及状态。
- 本地隔离构建通过，137 篇文章及 Pagefind、137 条结构化数据、141 评论区、6605 本地图片引用。主 JS 23049 B，仍低于 32000 B 预算。
- Chromium 1440/820/412px，首页/归档/阅读页，各明暗主题共 18 组实际验证：背景透明、局部表面和文字颜色、品牌、无横向溢出；首页当前页、下拉键盘/鼠标、搜索、滚动吸顶、移动菜单通过，测试范围无 JS 异常。此前归档悬浮、分页及键盘焦点回归通过。检查实际截图，最后修正归档标题居中。未完成 Safari/Android 真机、全站逐页或生产部署后的视觉验收。测试网络外部资源拦截，不代表实际网络性能。
