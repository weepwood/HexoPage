# HALO V2.2 · 原主题资源与动效精修

日期：2026-11-25。保持 V2.1 Butterfly 原布局、封面卡片、导航、侧栏及历史文章。旧标签不动；本版主站采用独立优化层。

## 远程字体

采用 Noto Sans SC 可变字体（400–700），Google Fonts API 通过 unicode-range 返回 WOFF2 分片，预连接、非阻塞样式表、font-display: swap 与系统中文字体后备。实测 API 返回 WOFF2（可变字重 CSS 112729 B 未压缩，较同一 API 四个单独字重 449300 B 减少约 75%）；Chromium 首页请求 17 个字体分片。远程服务在部分网络可能不可用，系统字体兜底。不恢复历史大型未压缩 TTF。

## 图片迁移

从实际 V2.1 生成页面及春季横幅清点 478 个外链来源，恢复 429 个（含旧 Blog 仓库找回 20 个，及两个括号截断路径修复），按内容哈希归档为 425 个文件，位于本仓库 `source/images/archive/`。成功来源原始合计约 180.65 MB，归档记录约 45.66 MB（含重复引用，实际目录约 44 MiB）。静态位图按长边 1800px 和 WebP 质量 85/90 转换，保留透明度、动画及必要 SVG 矢量图，原有较小文件保留。部分大型 SVG 保留以避免图表信息丢失。

49 个原始地址未恢复，主要为旧 OSS、失效域名及少量 SVG 安全/来源问题；构建使用明确的本地缺图提示，不继续请求失效服务器。完整来源、恢复状态和映射见 `butterfly-optimized/assets/images.json`。旧 Markdown 原文和标签仍保留来源用于追溯，当前发布页面构建时替换图片 URL。普通网页链接不改写，外部视频/评论等不属于图片迁移。原历史预览保持既有实现；V2.2 主站及其固定预览使用本地图片。第三方历史引用的再分发许可未逐一核实，发布者需根据来源确认授权；如存在争议，可移除对应资产并保留占位。

构建不进行下载，归档资源直接从 Git 读取。静态审计拒绝外部图片、内联背景及不存在的本地归档文件。构建时跳过图片模板处理，避免 SVG 中模板符号被 Hexo 误解析。

## 动态横幅

保留原春季 15 层画面及本地樱花素材，基于 pointer 坐标归一化、分层深度、指数平滑和 translate3d；左右最大偏移 72px，纵向 8px，透明图层按方向渐隐/渐显。鼠标离开平滑回中，稳定后停止 RAF；离屏/标签页隐藏停止。12 个轻量樱花粒子只在悬停时运行，触控设备及 reduced-motion 使用静态画面。无旧 OSS 或图库实时依赖。

## 视觉细节

不改变整体布局。精修导航字体、卡片圆角与阴影、封面 hover 微缩放、作者头像、元信息、正文行距、搜索浮层和暗色对比；保留键盘焦点与响应式布局。

## 实测

本地 Hexo 构建成功，137 篇文章全部生成；静态页面共检查 6605 个本地图片引用，无外部 img 或缺失本地文件；另检查并修复两个带括号的外链 CSS 背景。Chromium 1440px 验证 10 个首页卡片和 10 个封面、远程字体请求；归档页 15 个图层全部加载，单图层左右分别位移约 +32.86px/-35px，移出后 0px，12 粒子生成；375px 首页宽度无溢出，reduced-motion 不触发视差，测试范围内无 JS 错误、本地资源失败或外部图片请求。未完成全站人工视觉逐篇审查、真实移动网络 LCP 或历史预览的重新迁移。发布后另行确认 CI。
