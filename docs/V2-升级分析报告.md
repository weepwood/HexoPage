# HALO / HexoPage V2.0 架构与性能升级报告

日期：2026-11-25。基线：v1.0.0（70a1ac9aa9e438712a7ab17300e182027e184946）。

## 现状与决策

原 Hexo 5.4 / Butterfly 3.7.5-b3 使用旧依赖、Gulp、全站 CDN、统计脚本、动效与大型 XML 搜索索引。137 篇文章中包含大量 Butterfly 特有标签，直接迁移到不兼容的 Markdown 解析器存在丢失内容的风险。新版采用 Hexo 8.1.2 + EJS + 独立极简主题，保留原始 Markdown、兼容原 Apache-2.0 标签插件、继续纯静态托管，不引入 SPA、水合运行时、数据库或自建服务。

## 视觉与交互

以编辑式知识博客为定位：暖白/墨绿中性色、系统字体、单栏内容优先、细边框、克制装饰、响应式布局。首页仅展示品牌、文章列表和必要导航；正文增加可折叠目录、代码与表格横向滚动、注释、折叠、标签和上下篇。支持系统明暗主题与手动持久化、原生 dialog 搜索、键盘快捷键与 Escape、焦点样式、减弱动画。移动端 375px 下无首页横向溢出。

## 架构

- `source/`：唯一文章及历史资源来源，原文件不迁移、不覆盖。
- `modern/`：Hexo 8 依赖锁、配置、独立主题、临时构建准备器。
- `.github/pages/`：按不可变标签及提交清单构建；原版采用历史 Hexo 5，现代版采用 Hexo 8，最终合并为一个 Pages 产物。
- `/`：最新版本；`/versions/v1.0.0/`、`/versions/v2.0.0/`：固定版本预览；版本清单与 version.json 记录身份。
- 新版仅在需要时加载自托管 KaTeX；文章图片/iframe 延迟加载；搜索索引仅在用户实际输入时请求。
- 使用原始 create 字段补齐 8 篇未填写 date 的文章，另外 3 篇以已知仓库快照日期 2022-05-12 作为兜底（不是已证实发表日期）；不改 Markdown 原文。为 11 篇文章生成此前 2026-11-25 发布路径的跳转兼容页面。

## 实测（本地未压缩静态产物，非真实网络时延）

| 指标 | 历史版 | V2 |
| --- | ---: | ---: |
| 首页 HTML | 36139 B | 9661 B |
| 主题 CSS | 207967 B | 9104 B |
| 主要 JS | 36420 B（main + utils） | 约 2.7 KB |
| 搜索索引 | 8329408 B（全文 XML） | 26371 B（标题、分类、标签、摘要） |
| 内容文章 | 137 | 137 |

搜索范围有所收缩，索引降幅不能解释为等价全文搜索压缩。首次加载无需第三方网络资源；正文历史外链和按需数学字体不属于首页预算。没有宣称 Lighthouse 或实测 LCP 分数。CI 对首页 HTML（25 KB）、CSS（16 KB）、JS（8 KB）、默认搜索（100 KB）设硬上限，并逐条核实搜索文章路由、归档分类标签、RSS、Sitemap 与 404。

## 验收

- 本地锁定依赖安装和 Hexo 8 实际构建：通过，两种发布路径共 137 篇文章各自完整生成。
- Chromium 实测：根路径、版本子路径、首页 15 篇列表、文章详情、归档/分类/标签/关于、搜索 Hexo 命中 3 条、Escape 关闭、主题切换、375px 首页宽度，通过；测试范围内未出现 JS 异常和本地 HTTP 错误，首页第三方请求为零。
- 发布后需再次核实 Actions 和在线页面。未逐篇人工检查历史自定义标签、外链图片、公式与嵌入播放器，旧图床仍可能失效；V1 保留完整原始呈现和旧版全文搜索。
- 安全：发现旧配置中存在疑似历史凭据的注释，已从维护分支移除，不在报告复制；因 Git 历史与冻结标签仍存在，应由仓库所有者尽快在对应平台吊销并核验。此次不重写历史、不改标签。

## 后续方向

优先逐篇检查失效图床与特殊标签、建立资源授权及可迁移图片归档、对真实生产网络进行 Lighthouse/多设备实测；按需求增加按需全文搜索（分片或 Pagefind），而非恢复首页重负载。用户未指定具体视觉配色，本版选择低饱和编辑式设计；可独立替换主题，不改内容模型。
